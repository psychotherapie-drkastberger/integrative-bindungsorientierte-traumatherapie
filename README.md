# I.B.T.® Traumatherapie – Praxis Dr. Birgit Kastberger

Statische Website für GitHub Pages. Die Startdatei ist `index.html`; alle Bilder liegen im Ordner `assets`.

## Veröffentlichung

1. Neues öffentliches GitHub-Repository erstellen, zum Beispiel `ibt-traumatherapie-salzburg`.
2. Alle Dateien und den Ordner `assets` aus diesem Paket in die oberste Ebene des Repositorys hochladen.
3. Unter **Settings → Pages** die Quelle **Deploy from a branch** auswählen.
4. Branch **main**, Ordner **/(root)** auswählen und speichern.

Die Website ist anschließend unter `https://DEIN-GITHUB-NAME.github.io/ibt-traumatherapie-salzburg/` erreichbar.
